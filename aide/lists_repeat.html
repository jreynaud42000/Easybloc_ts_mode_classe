créer une liste avec l'élément … répété … fois

Bloc : lists_repeat

À quoi ça sert ?

Renvoie une liste qui contient plusieurs fois la même valeur : par exemple 5 scores qui valent tous 0.

Ce bloc renvoie une liste (à ranger dans une variable avec le bloc « définir … à … »).

Comment l'utiliser ?

Accrochez la valeur dans la première case et le nombre d'éléments dans la seconde.

Rangez la liste dans une variable avec le bloc « définir … à ».

À savoir

  • Pratique pour préparer une liste de départ, que l'on modifie ensuite avec le bloc « dans la liste … mettre n° … comme … ».

Exemple

Au démarrage, la liste « scores » reçoit cinq fois le nombre 0, puis elle défile : [0, 0, 0, 0, 0].
