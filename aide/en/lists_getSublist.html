in list … get sub-list from # … to # …

Block: lists_getSublist

What is it for?

Returns a new list made of a piece of the list: the items between two numbers, both numbers included.

This block returns a list (to store in a variable with the ‘set … to …’ block).

How to use it?

Attach the list, then choose the start and the end of the piece (#, # from end, first, last).

Good to know

  • The starting list does not change: the piece is a copy.

Example

At start, the board scrolls items no. 2 to no. 4 of the list [1, 2, 3, 4, 5]: [2, 3, 4].
