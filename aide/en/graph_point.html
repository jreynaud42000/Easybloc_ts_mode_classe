add the point X … Y … to curve …

Block: graph_point

What is it for?

Adds a point to the graph whose two values you choose: X (across) and Y (upwards). To plot a quantity against another one than time: the distance against the angle, the light against the position…

How to use it?

Attach a value to X and one to Y, and give the curve a name. The points of the same curve are joined in the order they arrive.

The graph shows in the Graph tab of the console.

Good to know

  • To measure against time, the ‘plot … on curve …’ block is simpler: it takes the time as X by itself.
  • The export button of the console saves the points in an Excel file.

Example

The ‘count’ loop makes x go from 0 to 10: each point has the value of x as X and its square (x × x) as Y. A parabola appears.
