… is empty

Block: lists_isEmpty

What is it for?

Returns true if the list has no item, false otherwise.

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Attach the list variable in the slot, then put the block in an ‘if’ block.

Good to know

  • Useful before taking an item: asking an empty list for an item stops the program with an error.

Example

At start, the ‘shopping’ list is empty: the board shows the sad face.
