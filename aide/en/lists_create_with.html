create list with …

Block: lists_create_with

What is it for?

Returns a list: several values (texts, numbers…) stored in order, under a single variable name.

This block returns a list (to store in a variable with the ‘set … to …’ block).

How to use it?

Attach a value in each slot, then store the list in a variable with the ‘set … to’ block.

To add or remove slots, click the gear of the block. With no slot at all, the block creates an empty list.

Good to know

  • Items are numbered from 1: the first item is no. 1.
  • A list can mix texts and numbers, but it is clearer to store only one kind of value in it.

Example

At start, three first names are stored in the ‘names’ list; each time the board is shaken, a first name picked at random scrolls.
