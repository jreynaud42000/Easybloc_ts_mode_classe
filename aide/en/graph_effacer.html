clear the graph

Block: graph_effacer

What is it for?

Clears all the curves and all the measurements from the graph, to start a measurement again from scratch.

How to use it?

Use it for example when a button is pressed, to redo a measurement without restarting the program.

Good to know

  • The names of the axes are kept.
  • A cleared measurement is no longer plotted: export it first (export button of the console) if you want to keep it.

Example

The temperature is plotted every 0.5 second. Pressing button A clears the graph: a new measurement starts.
