MP3 player on … : set the volume to … (0 to 31)

Block: grove_mp3_volume

What is it for?

Sets the volume of the Grove MP3 player (v3.0), from 0 (silent) to 31 (loudest).

How to use it?

Put it in ‘on start’, before playing a track, to start from a known volume.

Attach a number, or a value that changes: for example a potentiometer turned into a number from 0 to 31.

Good to know

  • A value below 0 becomes 0, a value above 31 becomes 31.

Example

The volume is set to 10, track 2 is played, then the volume goes up to 25 after 5 seconds.
