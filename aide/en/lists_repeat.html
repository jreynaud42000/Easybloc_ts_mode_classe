create list with item … repeated … times

Block: lists_repeat

What is it for?

Returns a list that contains the same value several times: for example 5 scores that are all 0.

This block returns a list (to store in a variable with the ‘set … to …’ block).

How to use it?

Attach the value in the first slot and the number of items in the second.

Store the list in a variable with the ‘set … to’ block.

Good to know

  • Handy to prepare a starting list, which you then change with the ‘in list … set # … as …’ block.

Example

At start, the ‘scores’ list gets the number 0 five times, then it scrolls: [0, 0, 0, 0, 0].
