effacer le graphique

Bloc : graph_effacer

À quoi ça sert ?

Efface toutes les courbes et toutes les mesures du graphique, pour recommencer une mesure à zéro.

Comment l'utiliser ?

Utilisez-le par exemple quand on appuie sur un bouton, pour refaire une mesure sans relancer le programme.

À savoir

  • Le nom des axes est gardé.
  • Une mesure effacée n'est plus tracée : exportez-la d'abord (bouton d'export de la console) si vous voulez la garder.

Exemple

La température est tracée toutes les 0,5 seconde. Un appui sur le bouton A efface le graphique : une nouvelle mesure commence.
