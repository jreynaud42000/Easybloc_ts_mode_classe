carte d'extension : Grove Shield V2.0

Bloc : carte_grove_shield

À quoi ça sert ?

Indique que le programme utilise la carte d'extension Grove Shield V2.0 (Seeed), sur laquelle la micro:bit est enfoncée et où l'on branche les modules Grove : le montage dessine alors cette carte.

Comment l'utiliser ?

Placez ce bloc dans « au démarrage ». Branchez ensuite les modules sur les prises de la carte : P0/P14, P1/P15, P2/P16 et I2C.

À savoir

  • Ce bloc ne produit aucun code pour la carte : le Grove Shield ne fait que relier les broches de la micro:bit à ses prises.
  • Sans ce bloc, la carte se choisit dans le menu du montage.

Exemple

La carte Grove Shield V2.0 est choisie, puis le buzzer branché sur P0/P14 sonne une demi-seconde.
