expansion board: BitMaker V2

Block: carte_bitmaker

What is it for?

Shows that the program uses the BitMaker V2 expansion board (Seeed), with its six Grove sockets and its four RGB LEDs: the wiring view then draws this board.

How to use it?

Put this block in ‘on start’. The blocks for the board LEDs also choose the BitMaker by themselves.

Good to know

  • This block produces no code for the board.
  • The sockets of the BitMaker are not those of the Grove Shield: check in the wiring view which socket each module goes into.

Example

The BitMaker V2 board is chosen, then its four LEDs light up in blue.
