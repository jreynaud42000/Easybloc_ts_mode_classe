expansion board: Grove Shield V2.0

Block: carte_grove_shield

What is it for?

Shows that the program uses the Grove Shield V2.0 expansion board (Seeed), into which the micro:bit is pushed and where the Grove modules are plugged in: the wiring view then draws this board.

How to use it?

Put this block in ‘on start’. Then plug the modules into the sockets of the board: P0/P14, P1/P15, P2/P16 and I2C.

Good to know

  • This block produces no code for the board: the Grove Shield only links the pins of the micro:bit to its sockets.
  • Without this block, the board is chosen in the menu of the wiring view.

Example

The Grove Shield V2.0 board is chosen, then the buzzer plugged into P0/P14 sounds for half a second.
