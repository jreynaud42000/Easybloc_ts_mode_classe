length of …

Block: lists_length

What is it for?

Returns the number of items in the list (or the number of characters in a text).

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Attach the list variable in the slot of the block.

Good to know

  • An empty list has a length of 0.
  • The last item has the number equal to the length of the list.

Example

At start, the ‘names’ list gets three first names, then the board shows its length: 3.
